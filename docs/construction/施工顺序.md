## miyu-render 施工顺序（设计 36 落地）

仓库：miyu-agent/miyu-render（公开），检出在 `~/Documents/github/miyu-agent/miyu-render`（2026-10-17 项目主人：重制版的仓库统一放在这个目录下）。

R-1 骨架和最短的一条路（已合，run 39045984214）
- Rust 一个 crate，程序 `bin/miyu-render`；只走协议（stdin/stdout JSON-RPC），不依赖核心 crate；单元测试用假核心。
- 清单：`[package]` 名字「渲染」、图标 `image`；`[process] args = ["serve"]`、`start = "always"`；`[export] methods = ["markdown"]`；`[settings]` 四项（设计 36 第七节）。
- 字体：系统的通用名（Linux 问 fontconfig，macOS、Windows 照默认名），缺中文另找一个补上，都没有的报错；配置能指定。
- 配色：一套主题六个颜色，`paper`、`light`、`dark`。
- 方法 `markdown {markdown, theme?}`：先只画段落和换行（排字、按透明度叠字），一页，经 `blob.put` 交核心，回 `{pages: [{blob, width, height}]}`。
- CI 三台：fmt、clippy -D warnings、doc、test、行数 500。
R-2 Markdown 全套，拆三步
- 上：块的读法和样子：标题、列表、任务、引用、代码块、分割线、链接补地址、裸地址、HTML 标签；粗体、斜体真字形（族里没有的加粗、倾斜）；代码里的中文用正文字体。
- 中：表格画成格子（列宽照内容分、表头底色、对齐、格子里换行）。已合（run 39047438290）。
- 下：分栏、分页、上限（照旧版的数）；超时、接住 panic；表情用彩色表情字体。已合（run 39048417077）。
R-3 mermaid（已合，run 39049169599）
- mermaid-rs-renderer 出 SVG，配色照页面的六个颜色；resvg 画成透明的图、按透明度叠到页面上；字号 24、最高 2200、导图树状。
R-4 公式（已合，run 39057070267）
- RaTeX 画独占一行的 `$$…$$`，颜色照正文；行内的 `$…$` 换成 Unicode 写法；画不出来的照 Unicode 写法排。
R-5 代码着色（已合，run 39058142198）
